# 10: CI

Status: done
Blocked-by: none

GitHub Actions workflow for the Rust workspace, building and testing on Windows and macOS runners. Written as .github/workflows/rust.yml (fmt check, clippy -D warnings, test, host build on windows-latest + macos-latest). It will run on the first push.

What done looks like:

- workflow runs cargo fmt --check, clippy, test on windows-latest and macos-latest
- mobile build not required in CI for now, add when green
- no Linux host jobs, ever (AGENTS.md rule)

Acceptance criteria: green run on a push, both OSes covered.

Notes: Robolectric for mobile is allowed only in Linux CI later, per ADR 0002.
