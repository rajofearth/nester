## What shipped

### Ticket 13 (server + host)
- `nester_core::display_root` strips `\\?\` (and `\\?\UNC\`) for display only. Applied to
  `/api/folders` root and host GUI folder rows. Canonical path untouched in config/IO, so
  folder ids and the phone's camera-upload bookkeeping survive. Verified on device:
  folders card now reads `C:\Users\Yashraj\Pictures`.
- `.nester-tmp` is infrastructure now: scan never indexes it, `entries_since` hides
  non-deleted staging rows but propagates their deletions (devices that hold them purge),
  and the upload path guard rejects `.nester-tmp` targets. On host restart 381 stale
  staging rows were marked deleted and 0 non-deleted staging rows are served.
  New Rust tests: `scan_skips_upload_staging_dir`, `staging_rows_purge_via_delta_pull`,
  `display_root_strips_win32_prefixes`.

### Ticket 12 (mobile gallery)
- Entries screen replaced by `GalleryScreen`: Photos / Videos / Files tabs with counts.
- Paging 3 over the in-memory index (page 120, no placeholders), `LazyVerticalGrid`,
  1:1 cells, stable path keys, contentType. Photos 4 columns, videos 3.
- Tiles: Coil `AsyncImage` from the local file when downloaded, neutral tile otherwise;
  play overlay on videos; progress bar + error badge during downloads; image loader is a
  remembered singleton with video decoder and 30% memory cache.
- Tap = download-then-open (system viewer with proper mime from extension). Long-press =
  Open / Delete sheet. Files tab: single-line rows with extension tile, size + dir,
  trailing delete icon (old screen was ~160px/row).
- Secondary drill-down: list icon opens "Show one folder" dialog; active filter chip with
  Clear; counts per tab update.
- New deps: `androidx.paging:paging-compose:3.3.6` only.
- JVM tests: `GalleryModelsTest` (classification, ordering newest-first, dir filter, mimes),
  `ListPagingSourceTest` (paging slices, refresh key, empty list), `BackupEndStateTest`.

### Ticket 13 (mobile)
- Camera backup DONE readout: "Finished - D of N backed up · S skipped · F failed" with
  error styling when anything failed, green "Backup complete" only on a clean run.
  Headlines during run use processed = uploaded+skipped+failed. Progress bar only counts
